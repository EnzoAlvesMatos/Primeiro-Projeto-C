<h2>🖨️ Como Instalar e Executar</h2>

<p>Para utilizar este projeto, é necessário ter o auxílio de uma IDE, como, por exemplo, o Visual Studio Code, ou um compilador online, como o myCompiler. Também é necessário ter um ambiente de execução compatível com a versão GCC-6.3.0-1.</p>
